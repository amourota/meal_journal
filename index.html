AI 연결 설정

실제 Gemini API로 분석해. 요청에 따라 API 사용료가 발생할 수 있어.
API 키는 이 브라우저의 localStorage에 저장돼. HTML 코드나 식사 기록 백업 파일에는 포함하지 않아. 단, 같은 브라우저에서 동일한 웹사이트 주소(동일한 출처)를 사용하는 다른 페이지의 JavaScript도 읽을 수 있으니 신뢰하는 페이지에서만 사용하고, 공용 기기에서는 저장하지 마. 가능하면 API 사용량 제한을 설정해 줘.

키를 입력하면 저장 옵션에 따라 브라우저에 보관돼. 저장을 해제하면 이미 저장된 키도 삭제하고 이 탭에서만 사용해. 이 앱은 자체 서버를 사용하지 않고 Gemini API로 직접 요청해.

음식별 예상 열량과 탄수화물·단백질·지방 범위를 확인할 수 있어. 과거 기록은 기존 열량을 유지하고 원하는 기록만 영양성분을 추가 분석할 수 있어.

데이터 백업

식사 기록과 AI 총평은 이 브라우저에 저장돼. 다른 기기와 자동 동기화되지 않아.

가져오기 전에 기존 기록을 백업해 줘. 가져올 때 같은 날짜의 기록은 백업본으로 대체돼.

사용 안내

음식의 양과 조리법을 정확히 모르면 열량 추정에 오차가 클 수 있어. 이 앱은 진단이나 개인 맞춤 영양 처방을 대신하지 않아. 하루 식사에 점수를 매기거나 식사를 거른 것을 칭찬하지 않고, 기록된 정보만 바탕으로 참고할 만한 의견을 제공하도록 설계했어.

AI 서비스에 요청할 때 입력한 식사 내용 및 분석 대상 날짜의 기록이 해당 회사로 전송돼. 민감한 건강 정보는 입력하지 않는 편이 좋아.
